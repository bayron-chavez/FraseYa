# Componentes Qt

FraseYa 0.2 utiliza PySide6, Shiboken6 y Qt 6.12.0 (Core, Gui y Widgets), bibliotecas dinámicas separadas del programa. Se distribuyen bajo LGPL versión 3, sin modificaciones de sus fuentes. Los textos LGPL y GPL que la complementa están en la carpeta de licencias del programa.

Se permite sustituir estas bibliotecas por versiones compatibles y depurar modificaciones de ellas conforme a la LGPL. No se aplica un bloqueo de sustitución. El código fuente correspondiente está en los repositorios oficiales, etiquetas v6.12.0:

- https://code.qt.io/cgit/qt/qtbase.git/
- https://code.qt.io/cgit/pyside/pyside-setup.git/
- https://download.qt.io/official_releases/qt/6.12/

Avisos de componentes de terceros: https://doc.qt.io/qt-6/licenses-used-in-qt.html y https://doc.qt.io/qtforpython-6/licenses.html.
